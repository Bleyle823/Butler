# Butler

Autonomous Economic Actor on Circle.

Hotel room-service demo: Webots ButlerServe robots, USDC escrow on Arc, credit and identity on peaq, KeeperHub as the operator.

Open [`worlds/hotel.wbt`](worlds/hotel.wbt) in Webots R2025a to see the hotel, the restaurant, and three ServeBots. Agent rules live in [`AGENTS.md`](AGENTS.md). Plugin source that judges should read lives in `packages/circle-plugin` and `packages/peaqos-plugin`.

Planning docs (`docs/PLAN.md`, `docs/scope/`, `docs/specs/`) stay on the operator machine and are not in git.
